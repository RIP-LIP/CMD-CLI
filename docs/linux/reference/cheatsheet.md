# Linux 命令速查表

按**用途**分组，不按字母排。每一组标明这条命令会不会动你的数据。

## 只读查看

| 命令 | 作用 | 改动数据 |
| --- | --- | :-: |
| `pwd` | 当前所在目录 | 否 |
| `ls -lah` | 列目录，含隐藏文件与大小 | 否 |
| `cat 文件` | 输出文件全文 | 否 |
| `less 文件` | 翻页读，可 `/` 搜索 | 否 |
| `head -n 20 文件` | 前 20 行 | 否 |
| `tail -n 100 文件` | 后 100 行 | 否 |
| `tail -n 100 -f 文件` | 实时跟随日志 | 否 |
| `wc -l 文件` | 数行数 | 否 |
| `df -h` | 磁盘占用 | 否 |
| `free -h` | 内存占用 | 否 |
| `ps aux` | 进程列表 | 否 |
| `tree 目录` | 目录树 | 否 |
| `file 文件` | 判断文件类型 | 否 |
| `du -sh 目录` | 目录总大小 | 否 |
| `stat 文件` | 权限、大小、时间戳 | 否 |

## 创建与修改

| 命令 | 作用 | 改动数据 |
| --- | --- | :-: |
| `mkdir -p 目录` | 建目录（已存在不报错） | 是 |
| `touch 文件` | 建空文件 / 改时间戳 | 是 |
| `cp 源 目标` | 复制 | 是 |
| `mv 源 目标` | 移动或重命名 | 是 |
| `echo "文本" > 文件` | 覆盖写入 | ⚠️ 是（覆盖） |
| `echo "文本" >> 文件` | 追加写入 | 是 |
| `chmod 权限 文件` | 改权限 | 是 |
| `chown 用户 文件` | 改属主 | 是 |
| `sed -i 's/旧/新/g' 文件` | 原地替换内容 | ⚠️ 是（不可逆） |

## 删除与清理

| 命令 | 作用 | 改动数据 |
| --- | --- | :-: |
| `rm 文件` | 删文件 | ⚠️⚠️ 不可恢复 |
| `rm -i 文件` | 逐个确认后删 | ⚠️⚠️ |
| `rm -r 目录` | 递归删目录 | ⚠️⚠️⚠️ |
| `rm -rf /` | 删整个系统 | ☠️ 别执行 |
| `find 目录 -name "*.tmp" -delete` | 按条件批量删 | ⚠️⚠️⚠️ |

::: danger Linux 没有回收站
`rm` 删掉就是删掉了。养成两个习惯：**手动删除一律加 `-i`**；**批量删除先把 `find` 结果存下来看一眼**：

```bash
find /tmp -name "*.tmp" > /tmp/to-delete.txt   # 先看
cat /tmp/to-delete.txt                          # 确认
xargs -a /tmp/to-delete.txt rm                  # 再删
```
:::

## 搜索与查找

| 命令 | 作用 | 改动数据 |
| --- | --- | :-: |
| `find 路径 -name "模式"` | 按文件名找 | 否 |
| `find 路径 -type f -name "*.conf"` | 只找文件 | 否 |
| `find / -maxdepth 3 -name "*.log"` | 限深搜索 | 否 |
| `grep "词" 文件` | 按内容找 | 否 |
| `grep -rn "词" 目录` | 递归找内容 | 否 |
| `grep -v "词" 文件` | 反向：不含该词的行 | 否 |
| `find 路径 -type f -exec grep -l "词" {} \;` | 找哪些文件含该词 | 否 |
| `find 路径 -type f \| xargs grep -l "词"` | 同上，文件多时更快 | 否 |

## 一条能直接复制的排查流水线

服务端「打不开」，按这个顺序敲。**顺序本身就是知识** —— 跳步会让你把时间花在错误的地方。

```bash
# 1. 进程还在吗
systemctl status 服务名 --no-pager

# 2. 端口在听吗
ss -tlnp | grep 8080

# 3. 本机能通吗（绕过 DNS 和外部网络）
curl -I http://127.0.0.1:8080/

# 4. 日志说了什么
journalctl -u 服务名 -n 50 --no-pager

# 5. 资源是不是满了
df -h / && free -h

# 6. 磁盘 inode 有没有耗尽（df 正常但写不了文件时查这个）
df -i /

# 7. 外部能不能通
ping -c 2 网关地址 && curl -I https://example.com
```

## 退出码

脚本里靠 `$?` 判断成败，这几个值有固定含义：

| 退出码 | 含义 | 常见来源 |
| :-: | --- | --- |
| `0` | 成功 | 全部命令 |
| `1` | 一般错误 | `grep` 没匹配到、`ls` 文件不存在 |
| `2` | 用法错误 | 缺参数、选项不认 |
| `126` | 找到了但不能执行 | 权限不足 |
| `127` | 命令不存在 | 拼错名字、`PATH` 里没有 |
| `130` | 被 Ctrl+C 中断 | 你自己按的 |

`grep` 没找到时返回 **1** 而不是 0，这是脚本里最常踩的坑：

```bash
# 错误：找不到时会走 else 分支
if grep "关键词" 文件; then echo "找到了"; else echo "没找到"; fi

# 正确
if grep -q "关键词" 文件; then echo "找到了"; else echo "没找到"; fi
```
